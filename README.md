# Parable × Google Cloud Website

A 3D interactive website showcasing the integration between Parable Enterprise Intelligence Platform and Google Cloud infrastructure.

## Features

- **Interactive 3D Background**: Three.js powered 3D cubes with Google Cloud color scheme
- **Particle System**: Dynamic particle background with connection lines
- **Responsive Design**: Fully responsive across all device sizes
- **Smooth Animations**: CSS and JavaScript animations throughout
- **Google Cloud Integration Showcase**: Detailed visualization of architecture and services

## Project Structure
├── index.html # Main HTML file
├── style.css # All styles (3D effects, gradients, animations)
├── main.js # 3D scene and interactivity
├── particles.js # Background particle system
├── README.md # This file
└── assets/ # Images and fonts (to be added)

## Google Cloud Services Featured

- **BigQuery**: Data processing and analytics
- **Vertex AI**: Machine learning and AI models
- **Looker**: Data visualization and dashboards
- **Google Workspace**: Real-time data integration
- **Cloud Storage**: Secure data storage
- **Dataflow**: Real-time data processing

## Deployment to GitHub Pages

1. Create a new repository on GitHub
2. Push all files to the repository
3. Go to Repository Settings → Pages
4. Select "Deploy from branch" and choose main/master branch
5. Your site will be available at: `https://[username].github.io/[repository-name]/`

## Customization

1. **Colors**: Edit CSS variables in `:root` section of `style.css`
2. **Content**: Modify text in `index.html`
3. **3D Objects**: Adjust parameters in `main.js` init() function
4. **Particles**: Modify `particles.js` for different effects
